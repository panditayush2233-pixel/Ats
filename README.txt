# SOMESH — Animated Portfolio

## Edit everything
- Main text, project names and sections: `index.html`
- Colors, fonts, layouts and animations: `style.css`
- Interactions, scroll reveals, menu and contact form: `script.js`
- Your portrait: `assets/profile.png`

## Deploy on Netlify
1. Extract this ZIP.
2. Open Netlify and choose Add new project → Deploy manually.
3. Drag the extracted folder into the deploy area.
4. No build command is required.

## Important
The contact form opens the visitor's email app using `mailto:`. For a server-side form, connect it to Netlify Forms or another form service later.

## Cinematic portrait update
The portrait is full-screen with no frame. On scroll it subtly moves/zooms toward the viewer, black sunglasses animate onto the face, and a stylized hand rises toward them. Timing is editable in script.js.
